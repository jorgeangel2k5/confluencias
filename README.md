# Confluencias

Sitio web interactivo desarrollado para la difusión y exploración de diversas manifestaciones artísticas y culturales (arte, música, cine y teatro).

---

## 🚀 Tecnologías Utilizadas

* **React** - Librería para la interfaz de usuario.
* **Vite** - Empaquetador y entorno de desarrollo rápido.
* **Tailwind CSS** - Framework de estilos para el diseño responsive.
* **React Router** - Navegación entre páginas (SPA).
* **React Icons** - Colección de íconos vectoriales.

---

## 📁 Páginas del Sitio

* **Inicio (`/`)**: Presentación del proyecto.
* **Categorías (`/categorias`)**: Exploración de proyectos por categoria artística.
* **Sobre Nosotros (`/sobre`)**: Información sobre el proyecto y el desarrollador.
* **404 (`*`)**: Rutas no encontradas.
